# Cassette World

一个可交互的 3D 磁带机网页：导入本地音乐，把歌曲摆进专辑柜，再通过拖动磁带、按键和旋钮播放。柜顶的 C-REC 刻录机会把可解码的音频输出为 MP3，桌面上的放大镜可检索歌曲和专辑。

## 打开

- **电脑体验：**下载本仓库的 `cassette-world.html`，用支持 WebGL 2 的浏览器打开。也可以下载 [Web App 文件包](cassette-world-web-app.zip)，解压后打开 `index.html`。
- **长期保存收藏：**把 `index.html`、`sw.js`、`manifest.webmanifest` 和 `icons/` 放在同一个 HTTPS 站点目录；也可在本机通过固定端口的 HTTP 服务打开。收藏与设置保存在该网址对应的浏览器存储中。直接打开本地文件适合体验，长期收藏建议使用固定网址。
- **iPhone：**将 Web App 文件包部署到 HTTPS 地址，在 Safari 打开后通过“分享 → 添加到主屏幕”使用。iPhone 上选择 MP3 保存位置要经过系统分享或下载面板。此版本尚未在实体 iPhone 上验证。

## 从导入到播放

1. 点击磁带机的 `INSERT AUDIO` 或专辑柜的导入按钮，选择本地歌曲；桌面浏览器也可把音频文件拖进页面。歌曲会进入单层专辑柜。
2. 打开抽屉并点击磁带选中，再点一次装入；也可把磁带拖向磁带机，靠近装载口时舱门会自动打开，松手放入。
3. 点击机身播放键。空格播放或暂停，`S` 停止，`E` 开关舱门，`M` 静音；方向键切歌、扫描或调整音量。

柜顶 `C-REC` 的 `IMPORT` 用于刻录 MP3。完成后磁带停在出口，可拖进磁带机或专辑柜；下一盘刻录完成时，前一盘会自动归档。点击出口磁带或 `MP3 ↓` 可保存文件。在设置中选择“更改保存文件夹”后，支持目录授权的浏览器会按歌手和专辑自动保存后续 MP3。

点击柜旁放大镜进入歌曲和专辑搜索。选择搜索结果后放大镜会举起查看磁带封面；点击或抓取场景里的磁带时，它会放回桌上。搜索面板的关闭按钮固定在顶部。左侧橙色螺丝盒可打开音量、机械音效、播放顺序、循环、声道和保存文件夹设置，底部还有内置使用说明。桌上的广告可切换磁带机外观。

## 文件与构建

| 路径 | 内容 |
| --- | --- |
| `index.html` / `cassette-world.html` | 已构建的单文件网页 |
| `sw.js`、`manifest.webmanifest`、`icons/` | Web App 与离线启动所需文件 |
| `work/` | Three.js 场景、音频处理、收藏和交互源码 |
| `使用说明.md`、`iPhone使用说明.md` | 详细操作与移动端说明 |
| `开发交接说明.md` | 结构、数据和后续开发约定 |
| `THIRD_PARTY_NOTICES.md`、`third-party/` | 第三方许可证及相关源码材料 |

在 `work/` 安装 `package.json` 中的依赖后运行 `node build.cjs`，生成的页面位于上一级的 `outputs/`。`package-deploy.py` 会整理网页和移动端文件包。网页不需要后端数据库或远程音频转换服务。

## 格式、存储和限制

导入支持 MP3、WAV、FLAC、AAC/M4A、OGG/Opus、WebM、AIFF、AU 等扩展名；具体能否播放或转码取决于浏览器的解码能力。刻录机还可处理源码中列出的部分加密格式，但格式版本或所需密钥不匹配时会显示错误。请只处理自己有权使用的音频文件。

音乐、封面、磁带位置和设置保存在当前浏览器的 IndexedDB，应用不会把音乐上传到服务器。浏览器、域名、端口或打开方式变化会产生不同的收藏空间；清理网站数据也可能移除收藏，请保留原始音乐和已导出的 MP3。刻录时为控制内存限制输入大小和时长，相关细节见 [使用说明](使用说明.md)。
