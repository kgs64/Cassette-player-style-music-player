
# Cassette World

单 HTML 的复古微缩音乐世界：机械磁带播放、单层专辑柜、MP3 刻录、放大镜收藏管理、双层歌词、在线点歌器与听歌偏好卡，支持音乐水面、雨雪和连续昼夜变化。

最近更新：2026-10-16 · 设置分类排版、桌面抗锯齿与纯音乐歌词识别

## 最近改进

- **设置分类**：播放与画面、环境与时间、歌词、收藏与保存、在线点歌、使用说明；标题和关闭按钮固定显示，滑块附数值反馈。
- **桌面抗锯齿**：提高桌面渲染分辨率，摄影模式最高使用 8 重多重采样（以设备支持为准），改善天线、梯子和机壳等细边缘；高分辨率会增加显卡负担。
- **纯音乐显示**：网易云 LRC 中仅含 JSON 制作信息、没有歌词正文时，显示“纯音乐，请欣赏”；兼容已导入的同类记录，含正常歌词的文件仍保留歌词正文。这是显示规则，不代表对音频进行了纯音乐识别。
- **连续时间**：天空、光照、水雪与星光随本机时间渐变；可用 60 秒快速模拟一天，停止或结束后恢复原时间模式。

本轮已验证设置分类与主要控件、Retina 渲染，以及提供的制作信息 LRC、混合歌词和历史记录兼容；网页启动未出现脚本错误。

## 在线体验

[直接打开 Cassette World](https://kgs64.github.io/Cassette-player-style-music-player/)

网页可以导入自己的音乐，也可使用在线点歌器。个人收藏保存在各自浏览器中，不会上传到仓库；首次打开需点击后才能播放声音。

## 5.22 修复

声道切换使用固定通道和平滑增益，避免切换后失声；首次在线点歌在点击时完成声音授权，装带后继续播放；连接失败保留机内磁带，按播放键可重试。Chrome 与 WebKit 已验证声道输出、装带、失败恢复和原有进度及播放列表功能。

## 使用

下载 `cassette-world.html` 后用支持 WebGL 2 的浏览器打开，可离线导入本地音乐。静态托管使用根目录 `index.html`、`sw.js`、`manifest.webmanifest`、`icons/` 与 `third-party/`；完整部署文件在 `cassette-world-web-app.zip`。在线播放或在线补全歌词需要网络。

## 文件安排

- 根目录 HTML 是构建产物与静态部署入口。
- `work/` 保存模块化源码、锁文件与验证脚本；第三方编码器源代码和许可在 `work/vendor/`。
- `legacy/` 保留旧验证文件、旧网页与历史 iOS 包，防止旧测试入口与正式入口混在一起；没有删除历史版本。
- 不上传浏览器收藏、用户音乐、密钥和本机依赖目录。

## 构建

在 `work/` 安装锁定依赖，然后执行 `node build.cjs`。源工程默认向上级 `outputs/` 输出；本仓库仅部署根目录，使用下列方式生成后复制到根目录：

```sh
mkdir -p outputs
cd work
npm install --ignore-scripts
node build.cjs
cp ../outputs/index.html ../index.html
cp ../outputs/cassette-world.html ../cassette-world.html
```

测试脚本使用独立浏览器和合成音乐，旧脚本中的浏览器路径、预览端口需按本机修改。清除网站数据可能移除收藏，保留原音乐或导出的 MP3。


## 新增操作

- 双击桌面偏好卡：先滑出、再抬起；关闭时先放下、再收回。记录皮肤、低音、高音和五段均衡器，可保存 24 组，附流行、人声、纯音乐、古典预设；切换保留音乐和音量。
- 放大镜收藏：每首已刻录 MP3 可独立下载；逐首勾选后可打包下载，未选择时不会下载整个收藏。筛选、封面行与显示排序帮助查找歌曲。
- 歌词便签：单击切换环境歌词、双击聚焦；设置中独立调整两层歌词字号、字体与背景墨色。
- 在线点歌器：使用桌面小型 MP3 播放器，正上方取景与可点击 HTML 屏幕；点歌卡变磁带装入，退带时变回卡片并滑回侧槽。
- 播放列表：收藏与点歌器共享命名列表，支持本地/在线混合歌曲、增删、替换和改顺序，磁带机按选定列表播放。

在线搜索默认使用 Audius 开放曲库，也可配置自有 Meting 兼容接口；静态 HTML 内嵌界面和客户端逻辑，外部曲库需联网。浏览器 IndexedDB 保存收藏，下载的单文件 HTML 不携带个人收藏。

## 环境与时间（2026-10-16）

设置中可分别开启音乐水面、雪地和音乐雨天，雨天可搭配水面或雪地。水面波纹随音乐及播放器音量变化。

“一天的光线”支持手动选择日出、日中、日落、夜晚，以及跟随本机时间连续渐变，天空、机身受光、水雪色彩与星光同步变化。采用固定的本地时刻曲线，未按地点和季节计算天文日出日落。“快速模拟一天”用 60 秒预览完整昼夜，可随时停止，结束后恢复原时间模式，音乐继续播放。

本轮使用隔离浏览器验证连续时间插值、跨午夜、天气联动，以及快速模拟的中途停止和结束恢复。

维护当前已交付网页的环境补丁时使用 `node work/build-water.cjs`（需要 `outputs/index.html` 和 `outputs/cassette-world.html`）。`work/app.js` 是较早的基础源码，直接执行完整 `build.cjs` 会覆盖后续网页补丁，尚需整理统一构建入口。

当前网页补丁构建顺序：保留现有 `outputs/` 双 HTML 后，按需运行 `node work/build-water.cjs`（包含设置分类）、`node work/build-edges.cjs`、`node work/build-lyric-credits.cjs`，再执行 `python3 work/package-deploy.py --web-only`。环境与歌词补丁均内嵌在 HTML 中，不需要额外脚本请求。
