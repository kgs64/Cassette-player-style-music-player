# 远岸烟火（2026-10-19）

设置 → 环境与时间 → 远岸烟火，默认关闭，可选疏朗或丰富。不会改变时段，不播放爆炸音。夜晚更清楚，时段系统控制可见度；水面沿用原反射通道。

## 编排和时钟
本地收藏及已转码歌曲有 audioBlob 时，OfflineAudioContext 异步解码到 11025 Hz，按块混合声道并让出主线程；Worker 提取 RMS、低频包络和瞬态/节拍候选，在宽乐句窗口选择代表重音，以歌曲内部相对强度压缩尺寸。统一使用现有 audio.currentTime，倒推 1.55–2.35 秒的发射时间。暂停冻结，跳进度和循环直接重建当前事件，不排队补放；轨迹和粒子寿命采用固定种子。每批最多三枚，粒子及烟雾使用共享缓冲，唯一补光不投影。

IndexedDB CassetteWorldFireworkScores/scores 缓存：稳定曲目 ID、音频大小、分析版本。缓存只包含编排，不复制音频。切歌或关闭后终止 Worker，旧异步结果通过 generation 作废。关闭清空活动缓冲，重新开启从当前进度接续。

## 来源支持范围
完整可解码 Blob：预分析。在线媒体只有 URL、不能获得完整 Blob 时：固定种子的稀疏氛围模式，设置中明确提示，不宣称预测重音，也不额外请求或绕过跨域。当前没有接入可读取 PCM 的网络前方缓冲，因此尚不支持滚动前瞻。大于 256 MB 或已知超过 45 分钟的音频也降为氛围模式，以避免解码占用过大；解码仍由浏览器 Web Audio 完成，特征提取在 Worker。

## 构建与验证
先运行 node work/build-fireworks.cjs（先独立打包 Worker，再内嵌整套模块），再执行网页打包与桌面构建。不要用旧 work/build.cjs 覆盖已交付的新版本。源码 app.js 也保留了入口，但交付 HTML 使用增量构建。

node work/fireworks-tests.cjs：种子、发射提前量、静音、事件间隔、跳转窗口、并发与力度限幅。
node work/fireworks-browser-tests.cjs：临时测试页面/独立浏览器收藏；实际 Worker、本地合成节奏与舒缓音频、三种形态、播放/暂停/恢复、连续跳转、归零模拟循环、切歌、缓存开关、在线降级、相机转动和现有水面共存。测试不读取个人音乐。

尚需用户试听实际曲目确认艺术节奏；尚未在真实移动设备、长达 45 分钟的文件、系统后台播放与所有浏览器版本上验收。触屏减少粒子并省略烟雾；减少动态效果进一步降低事件密度，隐藏页面不更新视觉。

- 发射位置覆盖远处天空的连续横向范围，包含磁带机正后方；保留世界坐标和原有远景距离。

- 同屏仍限制 3 枚，暂停、跳转和切歌继续由音频时钟重建，关闭后清空火线与光点。
- 浏览器验证实际 Worker 编排、连续拖动、暂停恢复、循环、切歌、缓存、无完整音频来源降级及相机旋转；生成三种形态与中央绽放连续阶段截图进行目视检查。真实歌曲的音乐表现仍需实际试听，自动检查使用合成音频。

### 视野一致性与远景柔化
- 使用主相机投影计算烟火中心的视野边缘淡出，主画面外的事件不写入火花/火线/烟雾缓冲，因此水面反射不会继续保留这一事件。相机移动时，即使音乐暂停也重新计算可见性。该处理针对画外来源，不进行机身遮挡的逐像素可见性分析。
- 连续火线改为共享三角带，以屏幕像素控制宽度并在横向使用高斯柔边，降低亮度，兼容主相机和水面反射相机的不同渲染尺寸；不模糊机身、文字或其他交互物体。

### 默认视野收拢（分析版本 6）
远岸位置改为两簇：相对远岸中心左右各 24–36 单位，约 12% 的候选保留中央位置；纵深保持 75–100 单位，绽放中心高度降低至 2–4，给展开和下垂轨迹留出上方空间。升空从绽放点下方 10 单位开始，保持可辨认的升空过程。缓存按新版本重新生成；频率与柔边处理不变。浏览器增加默认镜头投影检查，测试歌曲的候选中心均落在留有边缘余量的天空内，并查看三种形态和后续展开截图。自由旋转镜头仍可能让远岸移出视野，此时沿用边缘淡出。

### 小型背景烟火
在歌曲主编排之外，按稳定种子生成独立小烟火时间表：候选间隔 6.5–11 秒，主事件绽放前后 1 秒内不安排背景绽放；疏朗模式隔枚保留、丰富模式保留候选，实际频率会受避让影响。尺寸 1.7–2.4（主烟火约 2.7–5.7），亮度为主烟火的 55%，更远的后方两侧位置，桌面每枚 48 火花，不生成烟雾和机身补光。背景同屏最多 1 枚，总活动事件仍最多 3 枚；减少动态效果时省略这一层。共用开关、音频时钟、暂停、进度重建、切歌释放和画外反射淡出；不会改变主事件的重音编排。

### 升空可见性与柔化（分析版本 8，替代上节参数）

主烟火提前 2.1–2.7 秒发射，背景提前 1.8–2.3 秒发射。升空起点改为地表上方 0.35，绽放高度 5–7；路径从外侧轻微弯入绽放位置，避免旧路径从地面以下升起而被水面/地面遮挡。升空使用较亮暖色火点与约 0.63 秒逐渐消散的短尾迹，爆炸尾迹仍保持 0.085 / 0.14 / 0.24 秒。

### 2026-10-19 追加：退到背景里（分析版本 21）

上一版的亮度按"前景特效"给，结果烟花在画面里抢戏。这一版把它按"远岸背景"重新配平，并修掉升空弹的两个问题。

**升空弹**。原来只有一个白点，在 85 单位外被压到着色器 1.1px 下限，看着像一颗星；放大到 0.95 世界单位后又太大。现在是三层：暖色球 0.58 + 白热芯 0.24 + 6 颗沿尾迹掉落的火星（0.15–0.26，`(k/6+t·0.55)%1` 循环，所以是流动的引信而不是一根激光）。尾迹 span 0.42 秒、9 段、3.6px。

**整体退后**。`drawBurst` 里只有一个总开关：

```js
contrast*=.58*fade;   // 上一版是 .92
```

同时把单颗火花的增益从 3.2 / 2.4 降到 2.05 / 1.65，拖尾从 1.15 / 0.95 降到 1.0 / 0.80。降增益是必须的：3.2 的增益让每颗火花的 alpha 直接冲到 1.2 以上，片段着色器再乘 `.92+.52*hot`，中心一律削顶成白色 —— 这正是"调对比度看不出变化"的原因，0.92→0.80 时被削顶的像素根本没动。实测 0.92、0.80、0.58 三档，前两档在 280×220 区域的平均亮度只差 0.7/255，第三档才开始掉。

**光晕改成会长的**。原来是固定 30 世界单位的软斑，现在随壳一起长大、并比火花活得久：

```js
const halo=Math.exp(-age*1.7);
if(halo>.02)put(x,y,z,skin.main,contrast*halo*.085,12+e.size*.85*(1-Math.exp(-age*1.5)));
```

0.3 秒时半径约 15.5 单位（≈257px），1.5 秒时仍有 20.7 单位、alpha 约 0.007 —— 隔岸看到的那层"亮雾"就是它。

**可调入口**（都在 `work/ambient-fireworks.js`）：

| 想要的效果 | 改哪里 | 现值 |
| --- | --- | --- |
| 整体更亮/更淡 | `drawBurst` 首行 `contrast*=` | 0.58 |
| 单颗火花更实/更虚 | `pattern()` 里 `gain` | 2.05（外壳）/ 1.65（内芯） |
| 升空弹更大/更小 | `put(head…)` 的 0.58 与 0.24 | 0.58 / 0.24 |
| 光晕更厚 | `halo` 的 `.085` 与 `e.size*.85` | .085 / .85 |
